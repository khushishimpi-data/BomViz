# API

The live OpenAPI document is generated by FastAPI:

- Swagger UI: <http://localhost:8000/api/v1/docs>
- JSON: <http://localhost:8000/api/v1/openapi.json>

This page records conventions and the planned contract. Endpoints are marked with the phase
that delivers them.

## Conventions

- Versioned under `/api/v1`. Health probes are unversioned.
- JSON request and response bodies. File uploads use `multipart/form-data`.
- `Authorization: Bearer <access_token>` on every endpoint except register, login, refresh and
  health.
- List endpoints accept `limit` (default 50, max 200) and `offset`, and return
  `{items, total, limit, offset}`.
- Every response carries `X-Request-ID`. A client may send a safe value
  (`[A-Za-z0-9._-]{1,64}`) to correlate requests.
- Errors always use this envelope:

```json
{
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "BOM contains blocking validation errors.",
    "details": [],
    "request_id": "6f1c…"
  }
}
```

| Code | HTTP | Meaning |
|---|---|---|
| `VALIDATION_ERROR` | 422 | Request body or query failed schema validation (`details[].field`) |
| `UNAUTHENTICATED`, `TOKEN_EXPIRED`, `TOKEN_INVALID`, `TOKEN_REUSED` | 401 | Authentication problems |
| `FORBIDDEN` | 403 | Authenticated but the role lacks permission |
| `NOT_FOUND` | 404 | Missing, or in a workspace the caller cannot access |
| `CONFLICT`, `INVALID_STATE`, `DUPLICATE_UPLOAD`, `VALIDATION_FAILED` | 409 | State conflicts |
| `UNSUPPORTED_FILE_TYPE` | 400 | Not `.csv`, `.xlsx` or `.xls` |
| `FILE_TOO_LARGE` | 413 | Over 20 MB |
| `INTERNAL_ERROR` | 500 | Unexpected failure; message is generic, `request_id` identifies the log entry |

## Endpoints

### Health (Phase 0) ✅

| Method | Path | Response |
|---|---|---|
| GET | `/health` | `200 {status: "ok", version}` |
| GET | `/health/ready` | `200 {status: "ok", checks: {database, redis, storage}}` or `503` with `status: "degraded"` |

### Auth (Phase 1)

| Method | Path | Body | Response |
|---|---|---|---|
| POST | `/auth/register` | `{email, password, full_name}` | `201 User` |
| POST | `/auth/login` | `{email, password}` | `200 {access_token, expires_in, user}` + refresh cookie |
| POST | `/auth/refresh` | refresh cookie | `200 {access_token, expires_in}` (rotates cookie) |
| POST | `/auth/logout` | refresh cookie | `204` |
| GET | `/auth/me` | none | `200 User + memberships` |

### Workspaces and products (Phase 1)

`POST/GET /workspaces` · `GET /workspaces/{id}` · `POST /workspaces/{id}/members` ·
`POST/GET /workspaces/{id}/products` · `GET /products/{id}` · `POST /products/{id}/revisions`

### BOM workflow (Phases 2–4)

| Method | Path | Notes |
|---|---|---|
| POST | `/boms/upload` | multipart `file, workspace_id, bom_name, revision_label?, product_id?, product_revision_id?` |
| GET | `/boms` | filters `workspace_id, status, product_id, q` |
| GET | `/boms/{id}` | status, counts, jobs, mapping |
| GET | `/boms/{id}/file` | `{url, expires_at}` signed download (audited) |
| POST | `/boms/{id}/parse` | `{sheet_name?, header_row?, delimiter?, encoding?}` → `202 Job` |
| GET | `/boms/{id}/preview` | `stage=raw\|normalized`, sheets, detected options, columns, suggested mapping, rows |
| PUT | `/boms/{id}/mapping` | `{mappings: [{source_column_name, source_column_index, target_field, transformation?}]}` |
| POST | `/boms/{id}/validate` | `202 Job` |
| GET | `/boms/{id}/validation-report` | `format=json\|csv\|xlsx`, `scope=issues\|failed_rows` |
| POST | `/boms/{id}/import` | `{accept_warnings, exclude_error_rows?, confirm_exclusion?}` → `202 Job` (see ADR 0001) |
| POST | `/boms/{id}/retry` | Retry a `FAILED` job |
| DELETE | `/boms/{id}` | Soft delete |
| GET | `/templates/{csv\|xlsx}` | Blank BOM template |

### Visualization and analysis (Phases 5–6)

| Method | Path | Notes |
|---|---|---|
| GET | `/boms/{id}/items` | Paginated, filterable |
| GET | `/boms/{id}/tree` | `{roots, orphans, cycles, stats}`, with filters |
| GET | `/boms/{id}/flat?build_quantity=100` | MRP roll-up rows and totals |
| GET | `/boms/{id}/items/{item_id}/where-used` | Direct/indirect usages, paths, graph, cycle flag |
| GET | `/items/{part_number}/where-used` | Cross-BOM, filters `workspace_id, bom_id, product_id, revision_id` |
| POST | `/boms/diff` | `{baseline_bom_id, target_bom_id, view_mode, build_quantity?}` |
| GET | `/boms/{a}/diff/{b}` | `view_mode, only_changes, change_type` |
| GET | `/boms/{a}/diff/{b}/summary` | `{added, removed, modified, unchanged}` |
| GET | `/boms/{a}/diff/{b}/export` | `format=csv\|xlsx` |

### Exports (Phase 7)

`POST /boms/{id}/export` with `{export_type: BOM|FLAT|DIFF|WHERE_USED|VALIDATION_REPORT, format, parameters}`
→ `202` · `GET /exports` · `GET /exports/{id}` · `GET /exports/{id}/download` (fresh signed URL)
